## Decisions locked in this session

- **V/P values are strings (user casts); Run Params are typed.** Simplicity; matches "prefer simple IO".
- **Run Param schema source = `DAG(params=[...])` constructor arg**, persisted to `dag.params_json` — one schema source for hand- and UI-authored DAGs.
- **Resolve-at-trigger, freeze-to-run for non-secret config; secrets live via env, never on disk.** Determinism/audit for config; security for credentials.
- **MCP server = thin httpx client over the running REST API, NOT in-process import.** So chat-triggered runs keep executing in the persistent engine (fire-and-forget). Engine must be running.
- **MCP v1 library scope = existing DAGs** (read source + spec). Shared-function `lib/` deferred.
- **DAGs UI shape:** plain list + "runs" button → per-DAG page with run output dropdowns; do NOT reintroduce inline last-run/logs on the list. Audience is "just me for now" → optimize clicks over onboarding.
- **`example_etl` deleted intentionally by the user — do not restore.**

## Open questions
